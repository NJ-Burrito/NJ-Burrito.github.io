# Security policy

## In 10 seconds

- Found a security problem in the portfolio site? **Report it privately**, never in a public issue.
- Only the live site gets fixes.
- Never attach credentials, tokens or personal data to a report.

## Supported versions

| Version | Fixes |
|---|---|
| The live site (main branch) | yes |


## How to report

1. **GitHub private vulnerability reporting:** the repo's [Security tab](https://github.com/NJ-Burrito/NJ-Burrito.github.io/security) → **Report a vulnerability**.
2. Or the contact on the [portfolio](https://nj-burrito.github.io/#contact).

Include what you saw, the steps to reproduce it, and the version. You get an answer within 7 days.
