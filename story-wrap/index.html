What you get

A toolkit that runs the whole reel, and checks each stage.

Built for Arabic

Fully voweled voice text, caption shaping and right-to-left layout. Other languages are possible but untested.

Checked before it posts

Script, voice, every shot and the final reel pass machine gates, with a critic and a heal loop. Posting is a dry run until you pass --go.

You own everything it makes

No fonts, characters, voices or art are bundled. Your episodes, audience data and accounts stay in your own projects.

How it works

Six stages. Each leaves a file the next one reads.

  1. Script

    A script and a plan, checked by machine before anything is drawn.

    script.jsonDoc: WRITING

  2. Voice

    A local voice engine on your GPU. One take per line.

    work/voice/<ep>/<line>.wavDoc: VOICE

  3. Animate

    2D characters and sets. Each shot runs nine checked steps.

    shot.jsonDoc: RUNBOOK

  4. Sound

    Sound design, mix and audio checks.

    sfx.jsonDoc: SOUND

  5. Compose

    Captions follow the voice. Gates, a critic and a heal loop run until it passes.

    captions.json, episode.mp4Doc: COMPOSE, HEAL

  6. Publish

    Dry run first. Then --go posts to your Instagram, Facebook Page and YouTube.

    post.jsonDoc: AUDIENCE

What you need

Claude CodeYour own plan. The toolkit runs inside it.
Python and uvPython 3.10 or newer (3.11 for some scripts), run through uv.
Node and a browserNode 18 or newer, and a Chromium for rendering.
ffmpegFor audio and video.
A GPUNVIDIA, about 4 GB of free video memory, for the local voice engine. It installs into its own environment; the steps are in VOICE.md.
Your own assetsFonts, characters, worlds, and one CC0 reference clip per voice with its provenance.
Accounts, to postMeta and Google developer apps and tokens for Instagram, a Facebook Page and YouTube. Skip them and nothing posts.
SystemDeveloped and tested on Windows. macOS and Linux are not tested.

The toolkit is free (MIT) and calls no paid service. Your Claude Code usage is yours.

Install and check it runs

git clone https://github.com/NJ-Burrito/Story-Wrap
cd Story-Wrap
mkdir -p ~/.config/story-wrap
cp config/story-wrap.example.env ~/.config/story-wrap/story-wrap.env
uv run tools/daily.py --help

These five lines run on a clean checkout and print the command list. They do not make a reel.

Before your first reel you supply: fonts, characters and worlds, a voice reference clip, account tokens. Each has an example file in config/. No sample reel ships yet.

Questions

Is it free?

The toolkit is MIT and calls no paid service. You still need a Claude Code plan, and Meta and Google developer accounts if you post.

Do I need to code?

You work in a terminal with Claude Code. There is no editor window to click through.

Does it run on Mac or Linux?

Built and tested on Windows only.

Do I need a GPU?

For the local voice engine, yes: it checks for about 4 GB of free video memory before it starts.

Does it post by itself?

No. Posting is a dry run until you pass --go, and only to accounts you own, with your own tokens.
